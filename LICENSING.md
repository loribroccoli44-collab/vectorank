# Licensing options (no choice has been made)

No licence is applied to this repository yet, which means all rights are reserved. The code and the data differ in what
can be licensed, so they should be decided separately.

**Source code (`app/`, `lib/`, `scripts/`, `pipeline/`).** All of it is original work, so the author may choose:
- *MIT*: simplest; permits reuse, including commercial, with attribution.
- *Apache-2.0*: like MIT, plus an explicit patent grant.
- *AGPL-3.0*: requires anyone running a modified public service to publish their changes.
- *All rights reserved (current)*: viewable on GitHub, but not reusable.

**Data (`data/demo/`).** An open software licence should not be applied to these files as a whole: they derive from
third-party articles. Source sentences stay under each article's own licence (CC BY or CC0, attribution required). The
licence of the structured, machine-extracted fields has not been decided; it should be settled with a data-licensing
check before any open licence (for example CC BY 4.0) is stated.

**Images.** Illustrations in `public/` are the author's; screenshots in `docs/img/` show this application.
